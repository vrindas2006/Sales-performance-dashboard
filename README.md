# Sales Performance Dashboard

## Overview

This project was created as part of my Data Analytics Internship at VEDA Technology.

The objective of this project is to create a simple and interactive sales dashboard using Power BI to analyze sales performance.

## Tools Used

- Power BI
- CSV Dataset
- Microsoft Word

## Dashboard Features

- Total Sales
- Total Profit
- Total Quantity
- Average Discount
- Sales by Region
- Sales by Month
- Sales by Category
- Interactive Filters/Slicers

## Key Insights

- Compare sales performance across different regions.
- Analyze sales trends.
- Identify high-performing categories.
- Understand overall sales and profit performance.

## Files Included

- Power BI Dashboard (`.pbix`)
- Sample Superstore Dataset (`.csv`)
- Dashboard Explanation (`.docx`)

## Conclusion

The dashboard provides a simple and interactive way to understand sales performance and identify useful business insights.
